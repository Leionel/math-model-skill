# Editorial Style: Editorial & Visual System for Math Modeling

本文档约束数学建模论文的学术表达、图表排版、表格制作、公式符号与摘要撰写，旨在建立清晰、可信、克制且高可读性的编辑系统。

---

## 一、编辑与视觉四大核心原则

1. **真实优先**：视觉呈现不得掩盖错误比较、伪 Pareto 前沿、截断坐标轴或未说明的不确定性。
2. **层级优先**：每页、每图、每段只能有少量视觉主角；评委在 5–10 秒内应先看到核心结论，再看到证据与推导细节。
3. **一致优先**：同一对象在全文使用统一名称、单位、精度、颜色、线型和数学符号；图表与正文共享同一数据源。
4. **克制优先**：不追求“炫酷”或堆砌图表，而追求信息密度、可扫描性、黑白可辨与比赛模板内的规范专业感。

---

## 二、论证段落写作：CEEL 范式

所有结果分析与讨论段落，推荐采用 **CEEL 四步结构**，避免逐图报幕流水账：

1. **Claim（主张）**：段落首句直接给出本段要证明的核心结论；
2. **Evidence（证据）**：给出最少但必要的数值、基线对比差值、置信区间，并准确引用图/表；
3. **Explanation / Interpretation（机理解释）**：解释为什么出现该规律，背后的物理/数学/经济学机理是什么；
4. **Limitation / Boundary（适用边界）**：声明该结论依赖的前置假设、数据范围或失效边界，不作过度外推。

### 正反例示范
- ❌ **错误范例（流水账）**：
  > “图 3 显示了方案 A 的成本，图 4 显示了方案 B 的成本，从图 3 可以看出成本是 100 万元，图 4 是 90 万元，所以方案 B 更好。”
- ✅ **标准 CEEL 范例**：
  > “碳感知协同调度将可迁移计算负荷转向低电价且富余绿电的 Region E/F，使总成本和碳排放分别较基准下降 4.44% 和 5.29%（图 3–4）。机理在于两区域边际电价与边际碳排强度具有高度一致性，负荷转移同时释放了两项目标的协同改善空间；该结论依赖于当前六区域电网拓扑，不应随意推广至电价与碳排强度呈反向变动的极端区域。”

## 三、学术词汇证据解锁表 (Strong Words Unlock Table)

严禁在缺乏定量证据的情况下使用夸大修辞。只有满足相应证明义务时方可解锁使用：

| 词汇 | 允许使用条件 | 不满足时的规范改写 |
|---|---|---|
| **“显著”** | 明确经过统计假设检验（$p < 0.05$）或设定有预定义的工程重要性阈值 | “降低了 8.34 个百分点”或直接陈述数值差值 |
| **“全局最优”** | MILP 求解器返回 `OPTIMAL` 且 `actual_gap <= 1e-4`，且具有完整证明回执 | “当前求解配置下的高质量可行方案” |
| **“Pareto 前沿”** | 通过多目标严格非支配排序筛选（Non-dominated Sort） | “多权重参数扫描轨迹”或“候选折衷解集” |
| **“最重要杠杆 / 主导因素”** | 完成全要素敏感性分析或方差分解（Sobol 指数），具有排他性排序证据 | “在当前测试的参数范围内，该因素对目标影响最为敏感” |
| **“稳健 / 鲁棒”** | 经过极端扰动、参数扫描或独立测试集（OOS）验证 | “在 $\pm 20\%$ 参数扰动区间内，方案保持可行且目标波动低于 3%” |
| **“服务完全未受损”** | 覆盖了系统定义的所有服务质量（QoS）指标（如丢包率、排队耗时、吞吐量），而非仅仅单项时延 | “全部方案满足最大容忍时延约束” |
| **“完全可复现”** | 包含随机数种子、输入数据哈希、代码与运行环境回执 | “在固定随机种子与测试环境下测得” |

## 四、表格制作规范 (Three-line Table)

1. **统一采用标准三线表**（`\toprule`, `\midrule`, `\bottomrule`），正文禁止使用竖线和深灰底色；
2. **单位必须置于表头**，避免在每个单元格重复出现 `CNY`, `MW`, `kg` 等单位字符；
3. **数值集中适读化并按小数点对齐**：正文使用“百万元、亿元、万 t CO₂”，原始长整数保留在附录；
4. **加粗仅用于突出最优方案**：禁止整行、整列无意义滥用加粗；
5. **表注（Table Notes）说明一切口径**：在表底注明比较基线、样本量及缩写定义。

---

## 五、公式与符号排版规范

1. **正文变量使用纯原生 LaTeX**：严禁在正文中直接出现 `w_cost`, `P_load_t` 等代码下划线变量，必须规范书写为 `$w_{\mathrm{cost}}$`, `$P^{\text{load}}_t$`；
2. **单位使用直立体**：如 `$100\ \mathrm{MW}$`, `$50\ \mathrm{km/h}$`，数值与单位之间留有合适间距；
3. **重要公式单行居中并标号**：仅对正文后续有明确引用的关键公式进行编号（`\begin{equation}`），其余辅助推导使用无标号环境；
4. **长公式对齐**：使用 `aligned` 或 `split` 环境在等号或加号处对齐，禁止强制缩小字号塞入单行。

---

## 六、自解释图注 (Self-explanatory Caption)

图注不得仅包含简短标题（如“图 1 结果对比”），必须具备自足可读性（Self-contained）：
1. **图表对象与数据范围**；
2. **颜色、线型、Marker 的物理语义编码**；
3. **误差带、置信区间或样本量定义**；
4. **读者可安全得出的核心结论**；
5. **必要的边界与异常提示**。
