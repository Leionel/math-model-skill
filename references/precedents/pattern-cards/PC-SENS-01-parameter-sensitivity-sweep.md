# 参数敏感性专项

- **card_id**: PC-SENS-01
- **problem_family**: 全题型
- **trigger**: 主模型与结果完成后、撰写验证章节时；尤其当所有模型共用同一套敏感性模板的冲动出现时。
- **mechanism**: 按结论风险选择少量外生关键参数做受控扫描：固定其余条件，将目标参数取有依据的水平重跑模型，用曲线、区间或对照表呈现关键指标响应，并说明结论在哪些范围内稳定或失效。参数数量、水平和扰动形式由不确定性来源决定；数据驱动模型可对输入或训练过程做与实际噪声机制相符的重复实验。
- **dependency_shape**: 依赖主模型可重复运行与参数的外生性声明；对下游提供"结论在什么参数区间内成立"的边界证据。
- **validation_signature**: 敏感性类义务；须同时报告扰动设置（哪些参数、几水平、区间）与指标响应，禁止只给"灵敏度高/低"的定性句。
- **rhetorical_moves**: 选参数（为什么是它们）→扫描设置→曲线族/表→敏感排序→一句边界（结论对哪个参数最脆）。
- **failure_modes**: 扰动与结论无关的内生参数；所有模型共用一套敏感性模板；只报扰动后结果不报基线结果；敏感排序无依据（未给幅度）。
- **do_not_copy**: 不照搬任何一篇的参数选择集合、水平数与坐标范围。
- **source_ids**: B226, A127, 2400996, 2407093, 2424371
