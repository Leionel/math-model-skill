# 跨问承接

- **card_id**: PC-TRANS-01
- **problem_family**: 全题型
- **trigger**: 撰写第二个及以后的子问题、需要决定"沿用上一问什么、改什么"时；或发现后问与前问完全独立各写各的时。
- **mechanism**: 后问开头显式声明"沿用 X + 改动 Y + 理由 Z"：沿用上一问的结论排布或函数关系、只替换新增自由度（后问沿用前问的排布结论、把新增决策变量降维到每圈一组）；退化检查（当方向参数取特定值时后问退化为前问，从而只需修改部分表达式）；复用前问拟合的需求关系构造后问的规划目标；扩展式承接（在原模型上加物种与竞争因子回答生态影响问）。当问题间依赖与题面顺序不一致时，还可显式重排作答顺序并给出理由，让承接关系服从逻辑依赖而非题面编号。
- **dependency_shape**: 依赖上一问的结论性输出（排布规律、函数关系、拟合参数）；对下游提供论证连贯性与页数节约（避免重复推导）。
- **validation_signature**: 承接声明须可检验：沿用部分引用前问具体结论位置，改动部分说明为何不影响前问结论的有效性。
- **rhetorical_moves**: 与前问的联系与区别→沿用项→改动项与理由→（必要时）退化检查证明改动的一致性。
- **failure_modes**: 后问假装前问不存在、全部重推；沿用不声明（读者无法确认口径一致）；改动破坏前问约束却未重新检验；为承接而承接（沿用了与本问无关的结论）。
- **do_not_copy**: 不照搬任何一篇的承接句式与退化检查的具体参数值。
