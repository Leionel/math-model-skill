# 模型选型论证

- **card_id**: PC-SCOPE-01
- **problem_family**: 全题型
- **trigger**: 任何"本文采用 X 模型/算法"句式出现的位置；尤其当选型理由只剩"该算法流行"时。
- **mechanism**: 在选型处用 2-3 句完成"为什么是它而不是邻近替代"的对照论证，论据落在三类：可解释性与稳健性的权衡（可分解的预测模型介于黑箱与传统统计之间，兼顾解释与稳健）、变量结构适配（决策变量同时含 0-1 与连续量时需要混合编码的多目标进化算法而非标准单目标算法）、定义歧义的外部佐证（用行业规范或文献支撑对重叠率等有歧义的定义选择）。对照设计本身也可以是论证：用"理想参考-恒定-可变"三个平行模型使每条结论自带对照组，模型架构即论证结构。
- **dependency_shape**: 依赖备选模型/算法集合的枚举与题面变量结构；对下游提供模型章节开头的选型合法性，避免"无理由选型"。
- **validation_signature**: 无独立义务，但选型论证中引用的性质（可解释、稳健、混合编码）须在后文验证段落有对应证据落点。
- **rhetorical_moves**: 备选枚举→按题面特征对照→选定→一句被放弃路线的代价。
- **failure_modes**: 只报算法名不给理由；理由与题面特征无关（变量结构与算法能力错配）；引用文献佐证却不在参考文献落账。
- **do_not_copy**: 不复制任何一篇的选型句式或具体算法组合；不把某篇的备选对比当成通用选型表。
- **source_ids**: C235, C228, B311, 2405424
