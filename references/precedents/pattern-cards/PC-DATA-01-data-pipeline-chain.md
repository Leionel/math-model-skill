# 数据管道链

- **card_id**: PC-DATA-01
- **problem_family**: 预测 / prediction / 优化 / optimization
- **trigger**: 题给销售流水类大表（多附件、多年度、含缺失异常），最终要求定价/补货决策时。
- **mechanism**: 五段管道逐段交接：数据整合清洗（多表自然连接、One-hot、按日/周/月/年聚合、利润异常值与滞销品过滤）→分布与相关规律（自相关/时序分解/假设检验/相关系数/关联规则，按品类与单品两级展开）→价格弹性（双对数回归给出品类弹性系数与显著性，作为需求修正函数）→预测（LSTM 或 ARIMA+Prophet，报告拟合优度与残差）→优化决策（单目标启发式或多目标进化算法，含 0-1 选择变量与最小陈列量约束）。每段输出是下一段输入：弹性估计修正预测后的需求，预测值与批发价进入优化目标；末问的"还该采集什么数据"从管道断点反推。
- **dependency_shape**: 依赖附件原始表的清洗规则声明；对下游优化段提供需求函数与预测序列，对建议段提供"缺哪些数据"的证据。
- **validation_signature**: 预测段须报留出指标；优化段须与"平均/现状"基线对比收益提升；清洗规则须可复述（阈值与规则显式）。
- **rhetorical_moves**: 清洗规则→分布发现（带经济学解释）→弹性估计→预测与修正→优化与基线对比→数据缺口建议。
- **failure_modes**: 清洗规则不声明导致不可复现；跳过弹性直接优化（定价无需求响应）；预测与优化口径不一致（品类级预测用于单品级决策）；把相关性直接当定价依据。
- **do_not_copy**: 不复制任何一篇的清洗阈值、算法组合（LSTM/Prophet/NSGA-II 的具体搭配）与弹性回归的变量表结构。
- **source_ids**: C228, C235
