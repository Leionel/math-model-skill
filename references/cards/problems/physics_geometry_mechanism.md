# Problem Pattern Card: Physics/Geometry Mechanism (物理与几何机理题)

## 1. 典型业务结构
题目给出明确的物理/几何场景（弹道投放、视线遮挡、光学聚焦、结构受力、流体换热），要求推导运动/几何关系后做策略优化（2025 国赛 A 题烟幕弹即此型）。全部常数来自题面，通常无观测数据附件。

## 2. 常见比赛翻车陷阱
- **机理未推导先套算法**：跳过运动学/几何推导，直接对策略参数上遗传算法，评审看不到模型只有搜索；
- **常数想当然**：重力加速度取 9.81 还是 9.8、是否计空气阻力未声明、未做敏感性；
- **判据含糊**：核心判定（如"遮蔽"）没有数学定义——是单视线、全部视线还是概率遮挡？口径不同结论量级不同；
- **数值精度冒充机理**：离散仿真步长不声明，或把网格搜索最优说成连续最优；
- **单位与坐标系漂移**：度/弧度、水平面基准、时间原点在多问之间不一致。

## 3. 标准推荐实战流水线
1. **约定合同**：坐标系、时间原点、单位、常数（含 g 与取舍）全部写入 model_contract 的 `scope_contract` 与 `parameter_plan`（`GIVEN` provenance 指向题面原句）；
2. **判据形式化**：把"有效/成功/遮挡"翻译成可计算的数学条件（如"每条视线段与球相交"），歧义处走 `assumption_forks`（至少两种解释 + 判别检查）；
3. **机理推导**：先写运动学/几何闭式（弹道方程、交点条件），固定策略（问题 1 型）用双方法复算（细步长积分 + 事件二分）；
4. **策略优化**：以机理为约束做参数优化（网格 + 局部精化/DE），报告搜索预算与"非全局最优"边界；
5. **独立复核与单调性**：独立实现重算关键量；资源增多（弹数/设备数）的解不得劣于其子集问题（资源单调性）。
