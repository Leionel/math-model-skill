# Problem Pattern Card: Spatial & Facility Scheduling (空间资源与设施多时段调度)

## 1. 典型业务结构
多个地理分布的作业空间/设施（如数据中心计算节点、工厂车间流水线、泊位港口、变电站），在多个离散时间窗口内处理动态到达的作业负荷，需要优化空间迁移、时间平移与设备启停状态。

## 2. 常见比赛翻车陷阱
- **忽略迁移时延与网络传输代价**：只算计算/处理成本，未将数据跨境/跨区网络传输时延和带宽成本纳入硬约束；
- **设备爬坡速率（Ramp-rate）与启停时间缺失**：将大型机组/设备当作可无限瞬时开关；
- **状态连续性断裂**：第 $t$ 周期末状态与第 $t+1$ 周期初状态未通过时序方程严格绑定。

## 3. 标准推荐实战流水线
1. **构建三维决策变量张量**：$x_{i, j, t} \in \mathbb{R}_{\ge 0}$（从节点 $i$ 迁移至节点 $j$ 在时刻 $t$ 执行的作业量）；
2. **设立容量与物理守恒约束**：
   - 节点局部处理容量上限：$\sum_i x_{i, j, t} \le \text{Cap}_{j, t}$；
   - 跨区传输带宽上限：$x_{i, j, t} \le \text{Bandwidth}_{i, j}$；
   - 任务最大容忍时延约束：$\text{Delay}_{i, j} \le \text{MaxTolerance}_i$；
3. **分时电价与绿色能源协同**：将目标函数分解为基础电费、碳配额费用、网络传输费及设备折旧损耗之和；
4. **Baseline 对比设计**：
   - 本地就地处理基线（No Migration Baseline）；
   - 启发式贪心最快迁移基线。
