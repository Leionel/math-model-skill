# Problem Pattern Card: Forecast-then-Optimize (预测 → 优化框架)

## 1. 典型业务结构
题目先给定历史时序/面板数据（如新能源出力、客户需求量、农产品市场售价），要求预测未来阶段数据，并基于预测值（或其分布）进行调度、排产或资源配置决策。

## 2. 常见比赛翻车陷阱
- **数据穿越与泄漏（Data Leakage）**：预测模型使用了未来时间步的特征进行训练；
- **确定性假象（Point Forecast Illusion）**：将预测均值直接当作绝对确定真值输入优化，忽视了预测误差（Residual Error）对优化可行域与成本的非线性冲击；
- **缺乏 Baseline 比较**：预测模型使用了复杂 LSTM/Transformer，但准确率甚至不如 Seasonal Naive 或滑动平均；
- **优化对预测误差极敏感**：轻微的预测偏差导致优化问题在极端时段不可行。

## 3. 标准推荐实战流水线
1. **建立 Baseline 预测**：先计算 Seasonal Naive / Historical Average 作为最低参考基准；
2. **构建主预测模型**：建立 Holt-Winters / ARIMA / LightGBM，通过严格的时间切分（Time-based Train/Val/Test Split）评估；
3. **残差分布建模与情景生成**：提取预测残差序列 $e_t = y_t - \hat{y}_t$，拟合分布并生成 $S$ 个离散未来情景或置信区间；
4. **随机/鲁棒优化建模**：将情景集或不确定集合输入优化模型，求解对冲风险的最优决策；
5. **预测误差敏感性回测（Sensitivity Backtest）**：在真实测试集上评估“预测误差下实际方案的约束满足率与实际收益”。
