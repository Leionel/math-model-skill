# Problem Pattern Card: Vehicle Routing Problem with Time Windows (带时间窗的车辆路径规划 VRPTW)

## 1. 典型业务结构
一支车队从中心仓库（Depot）出发，为分布在不同地理坐标的多个客户点配送货物，每个客户点具有特定的需求量与服务时间窗口 $[e_i, l_i]$，要求在满足车辆载重上限与时间窗的前提下，最小化总行驶距离、车辆启用固定成本或客户等待惩罚。

## 2. 常见比赛翻车陷阱
- **忽略车辆最大载重硬约束（Capacity Overload）**：路径规划总需求超过单车额定吨位；
- **子回路消除约束（Subtour Elimination）缺失**：生成脱离仓库独立循环的“空中飞车”伪路径；
- **时间窗到达早晚处理不当**：早于 $e_i$ 到达可以等待（产生等待时间），但晚于 $l_i$ 到达属于硬性不可行或产生巨额延迟违约惩罚。

## 3. 标准推荐实战流水线
1. **构建三指标图模型**：
   - 决策变量 $x_{i, j, k} \in \{0, 1\}$ 表示车辆 $k$ 是否直接从节点 $i$ 行驶至节点 $j$；
   - 连续时间变量 $s_{i, k} \ge 0$ 表示车辆 $k$ 到达并开始服务节点 $i$ 的时刻；
   - 车辆剩余载重变量 $u_{i, k} \ge 0$；
2. **三组核心约束体系**：
   - **度数平衡与流守恒**：每个客户点恰好被一辆车访问一次，且从仓库出发最终返回仓库；
   - **载重累加递推**：$u_{j, k} \ge u_{i, k} + q_j - M(1 - x_{i, j, k})$；
   - **时间推进与消除子回路（Big-M 紧约束）**：$s_{j, k} \ge s_{i, k} + t_{ij} + d_i - M(1 - x_{i, j, k})$；
3. **求解策略分级**：
   - 小规模（客户数 $N \le 25$）：调用 PuLP / SciPy HiGHS 精确求解 MILP；
   - 中大规模（客户数 $N > 30$）：采用自适应大邻域搜索算法（ALNS）或带精英保留的遗传算法（GA）。
