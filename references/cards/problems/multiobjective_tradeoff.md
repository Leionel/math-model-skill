# Problem Pattern Card: Multi-Objective Optimization & Pareto Analysis (多目标权衡与Pareto前沿)

## 1. 典型业务结构
系统同时存在多个相互冲突的优化目标（如：降低经济成本 vs 降低碳排放；提升服务响应速度 vs 压缩设施投资预算；最大化收益 vs 最小化尾部风险），无法存在单一解在所有目标上同时达到最优。

## 2. 常见比赛翻车陷阱
- **伪 Pareto 前沿（Dominated Points Mislabeled as Pareto）**：未做非支配排序，将包含劣解的散点强行连成曲线称为 Pareto 前沿；
- **简单线性加权权重设置无依据**：写出 $f = w_1 f_1 + w_2 f_2$ 但未做量纲归一化（如万元与吨直接相加），导致大数值指标完全主导目标；
- **非凸前沿上权重法失效（Duality Gap）**：在真实 Pareto 前沿存在凹陷区域时，简单线性加权无法扫描出凹区域的最优解。

## 3. 标准推荐实战流水线
1. **统一目标量纲化处理**：
   采用理想点法（Ideal Point）归一化：$f_k^{\text{norm}}(x) = \frac{f_k(x) - f_k^{\min}}{f_k^{\max} - f_k^{\min}}$；
2. **多目标求解算法推荐**：
   - **$\epsilon$-约束法（$\epsilon$-Constraint Method）**：将其中一个主要目标作为优化目标，其余目标转换为不等式约束 $f_j(x) \le \epsilon_j$，通过系统步进改变 $\epsilon_j$ 扫描完整前沿（能有效求解非凸前沿！）；
   - **NSGA-II 快速非支配遗传算法**：适用于大规模复杂非线性组合黑箱多目标问题；
3. **真实 Pareto 非支配性核验**：
   对生成的候选解集合执行支配关系检验（若存在解 $B$ 使 $f_k(A) \le f_k(B)$ 对所有 $k$ 成立且至少有一项严格小于，则剔除解 $B$）；
4. **妥协解优选（Compromise Programming / TOPSIS）**：
   从非支配前沿中，利用到理想点欧氏距离最近准则选出推荐的最佳折衷运行点（Knee Point）。

## 4. 论文逻辑组织建议 (CEEL 范式)

- **图 2**：边际替代率折线图（Marginal Tradeoff Rate: 每减少 1 吨碳排放需额外支付的边际经济成本）；
- **论证段落**：详细分析目标间的冲突机制，为不同风险偏好的决策者提供定制化的情景决策建议。
