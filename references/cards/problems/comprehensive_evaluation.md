# Problem Pattern Card: Comprehensive Evaluation (综合评价类)

## 1. 典型业务结构
题目给出一组对象（城市/方案/企业/产品）与多个指标（常混合效益型、成本型、定性等级），要求"建立评价模型并排序/分级/选优"。国赛 C 题、部分 B 题与美赛 E 题高频出现。

## 2. 常见比赛翻车陷阱
- **指标体系拍脑袋**：指标选取无依据（题面/文献/数据支持），删指标加指标全凭结论方便；
- **权重来路不明**：AHP 一致性比率不达标仍硬用、熵权与 AHP 随意组合不打招呼；
- **方向未处理**：效益型/成本型指标混在一起归一化，"越小越好"的指标贡献为正；
- **方法堆砌**：TOPSIS + 灰色关联 + 模糊评价三个都算，结论不一致时装作没看见；
- **排序无稳定性**：权重轻微变化 Top3 洗牌，论文只报一次排序结果。

## 3. 标准推荐实战流水线
1. **指标体系论证**：每个指标给出题面出处或文献/数据依据；相关性高的指标合并或降维（PCA/熵权自动加权前先看共线性）；
2. **规范化**：效益/成本/固定型分别正向化，再极差或 z-score 标准化（口径全文唯一）；
3. **权重**：客观（熵权/CRITIC）与主观（AHP，CR ≤ 0.10 才可用）分别计算并报告组合方式；主观权重标 `ASSUMED` 绑敏感性；
4. **聚合与排序**：主方法（TOPSIS/灰色关联/模糊综合评价任选其一为主）+ 一个 Baseline（简单加权和）对照排序一致性；
5. **稳健性**：权重 ±10%/±20% 与换归一化方式重跑（逐格真实重算），报告 Top3 稳定率与翻转样本的逐条解释。

## 4. 论文逻辑组织建议 (CEEL 范式)
- **图 1**：指标体系结构图（含方向标注与来源）；
- **图 2**：权重扰动下排序稳健性（如 rank 变动带状图/热图）；
- **论证段落**：按 Claim→得分比较→与 Baseline 一致性→边界（"评价结论依赖所选指标与权重口径"）组织；对排序临界样本（得分接近）单独讨论，不硬性宣布优劣。
