# Problem Pattern Card: Small-Sample Forecasting (小样本预测题)

## 1. 典型业务结构
题目只给 5–20 期年度/阶段数据，要求预测未来 2–5 期（人口、产量、能耗、水质指标等）。时间跨度长、样本少是本质约束，模型族选择比调参更关键。

## 2. 常见比赛翻车陷阱
- **深度模型小样本过拟合**：10 个点训练 LSTM/Transformer，训练误差极小、外推完全失真（见 failures/small_sample_overfit）；
- **灰色预测远程外推**：发展系数超出适用区间仍预测 10 期（见 failures/grey_extrapolation_abuse）；
- **无留出检验**：所有数据用来拟合，报告拟合误差冒充预测精度；
- **忽略区间**：只报点预测，不给区间；小样本下区间比点值更重要；
- **趋势断点**：政策/结构变化点（如疫情年）被当成可平均的噪声。

## 3. 标准推荐实战流水线
1. **数据体检**：画全序列图，标出断点/异常点并说明处理（剔除/分段，不能悄悄删）；
2. **Baseline**：Naive（末值）、线性趋势、最近三年均值三个最低基准；
3. **主模型选型**：单调小样本 → GM(1,1)（报告 $-a$ 区间与 C/P 检验）；带季节 → Holt-Winters；样本勉强够 → ARIMA；机理明确 → 机理外推（如 Logistic 饱和模型）；
4. **留出回测**：至少留最后 2 期做样本外检验，主模型须优于 Baseline 才可声称有效；
5. **区间预测**：残差 Bootstrap 或正态近似给出预测区间；预测期数超过留出验证范围的部分降级为"趋势参考"。
