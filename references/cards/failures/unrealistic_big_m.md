# Failure Card: Arbitrary Huge Big-M Constant (Big-M常数设置过大导致数值病态)

## 1. 错误形式
在将分段线性、逻辑条件（$y=1 \implies x \ge L$）或时间窗约束进行线性化重构时，作者直接随意写出：
\[
x \ge L - M(1 - y), \quad \text{其中 } M = 10^9 \text{ 或 } 10^{12}
\]

## 2. 为什么错
- **浮点数舍入与数值病态（Numerical Instability）**：在标准的混合整数规划求解器（如 HiGHS / Gurobi / CPLEX）中，默认整数可行性容差通常为 $10^{-6}$；当 $M = 10^9$ 时，极小的连续松弛变量 $1 - y = 10^{-6}$ 乘以 $M$ 后等于 $1000$，足以导致约束彻底失效或产生数值漏解；
- **松弛松散（Loose LP Relaxation）**：过大的 $M$ 会导致线性松弛界（Dual Bound）极度松散，分枝定界树（Branch-and-Bound Tree）急剧膨胀，导致求解器在比赛 72 小时内跑爆内存或超时卡死。

## 3. 最小反例
- 变量 $x \in [0, 100]$，要求当 $y = 0$ 时 $x \le 0$；
- 采用 $x \le M y$，设 $M = 10^9$；
- 求解器在某一节点解出 $y = 10^{-7}$（在 $10^{-6}$ 容差内被判定为 $y=0$），但 $M y = 100$，求解器判定 $x = 100$ 合法！
- 最终输出 $y=0$ 却 $x=100$ 的非法逻辑错误解！

## 4. Harness 应如何发现与拦截
- **Big-M 紧上界检查（Tight Bound Verification）**：扫描模型合同中的 Big-M 常数，强制要求 $M$ 必须由物理约束的最大可能极差推导确定（例如 $M = \max(x) - \min(L)$）；
- 若 $M > 10^5$，触发数值警告并要求提供紧确性证明。

## 5. 论文中如何正确表达
“根据地块最大总面积与单产上限，推导出紧确上界 $M = \max_{i} \text{Area}_i = 120\text{ 亩}$，避免使用过大松弛常数引发数值精度病态。”
