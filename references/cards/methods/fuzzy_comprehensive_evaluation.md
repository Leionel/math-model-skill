# Method Card: Fuzzy Comprehensive Evaluation (模糊综合评价)

## 1. 解决什么问题
评价对象带有主观/模糊语义指标（"较满意""基本合理"）的综合排序：服务质量、方案优选、安全等级评估等难以精确量化的评价题。

## 2. 不适合什么问题
- 指标全部可客观测量（此时加权 TOPSIS/熵权更透明，模糊化只增加可质疑的自由度）；
- 需要可复现的客观结论（隶属函数选取带主观性，评审可质疑）；
- 指标间强相关且未处理（模糊合成不解决共线性）。

## 3. 最低数据条件
- 明确的指标集 $U$ 与评语等级集 $V$（等级数建议 4–7）；
- 每个指标对每个等级的隶属函数或隶属度表（来源必须登记）；
- 权重向量（AHP/熵权/组合，来源同 topsis_entropy 卡要求）。

## 4. 核心数学结构
\[
B = W \circ R = (b_1, \dots, b_m), \qquad R = [r_{ij}]_{n \times m}, \; r_{ij} = \mu_{V_j}(u_i)
\]
$W$ 为权重向量，$R$ 为单因素隶属度矩阵，$\circ$ 取 $M(\cdot,+)$ 加权平均型（可复现）；结果按最大隶属度原则定级，或按等级加权得分排序。

## 5. 参数来源要求
- 隶属函数类型（三角/梯形/正态）与参数须标 `ASSUMED` 或 `CALIBRATED`（给拟合/调查依据）；
- 权重来源按 AHP/熵权卡的 provenance 要求登记。

## 6. 推荐 Baseline
- 简单加权求和（不模糊化）的排序；
- TOPSIS 排序；两法排序一致性（Spearman 相关）应报告。

## 7. 必须验证的东西
- **权重扰动敏感性**（`sensitivity` 义务）：权重 ±10%/±20% 重跑，排序 Top3 是否稳定；
- **隶属函数扰动**：换一种隶属函数（三角↔梯形）后等级是否翻转；
- **与 Baseline 排序一致性**：不一致的样本须逐个解释；
- 最大隶属度原则失效时（$b_{max}$ 与次大接近），必须用加权得分而不是硬取最大。

## 8. 常见数学错误
- 用 $M(\vee,\wedge)$ 取小取大型合成但指标数多时信息全部淹没（$b$ 几乎全 0）；
- 隶属函数越界（$\sum_j r_{ij} \ne 1$ 未归一）；
- 等级分（如"优=95 分"）直接当连续数值平均，丢失模糊语义。

## 9. 常见代码错误
- $R$ 矩阵按指标/等级方向转置写反；
- 归一化在合成之后做（应先归一隶属度再合成）。

## 10. 论文表达规范
- 正文必须交代权重来源、隶属函数和合成算子；只有当函数形状或扰动响应承担关键证据时才画图，否则用公式、表或附录更紧凑地呈现。扰动方案数量由结论风险决定，不固定为两套；
- 结论写"在给定隶属标准下评为 X 级"，不得写"客观上属于 X 级"。

## 11. 典型优秀论文机制
- 模糊评价 + 灰色关联/TOPSIS 双法互检，报告排序一致率；
- 对"临界样本"（两等级得分接近）单独做边界讨论。

## 12. 推荐实现入口
numpy 矩阵运算即可；隶属度矩阵与权重须落盘为 artifact 供 `sensitivity_experiment` 逐格重跑。
