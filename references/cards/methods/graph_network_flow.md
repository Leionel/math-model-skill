# Method Card: Graph Theory & Network Flow (图论、最短路与网络流模型)

## 1. 解决什么问题
交通路线导航、物流配送、管道流体输送、应急物资调拨、社交网络关键节点识别、关键路径法（CPM）工程调度。

## 2. 不适合什么问题
- 连续介质流体力学问题；
- 节点/边权重完全随机且无任何拓扑关联的问题。

## 3. 最低数据条件
- 拓扑图 $G = (V, E)$，其中 $V$ 为节点集，$E$ 为边集；
- 边的属性矩阵：容量 $c(u, v)$、距离/费用 $w(u, v)$、有向性（有向/无向）；
- 需求向量：各节点的产出（源点）与需求（汇点）。

## 4. 核心数学结构
1. **最小费用最大流（Min-Cost Max-Flow）**：
   \[
   \min \sum_{(u, v) \in E} w(u, v) f(u, v)
   \]
   \[
   \text{s.t.} \quad \sum_{v} f(u, v) - \sum_{v} f(v, u) = b(u), \quad 0 \le f(u, v) \le c(u, v)
   \]
2. **TSP 消除子回路约束（MTZ 约束）**：
   \[
   u_i - u_j + n x_{ij} \le n - 1, \quad 2 \le i \neq j \le n
   \]

## 5. 参数来源要求
- 距离矩阵 $w_{ij}$ 必须声明是欧式距离、曼哈顿距离、高斯投影球面距离（Haversine）还是路网真实耗时矩阵（`GIVEN` / `DERIVED`）。

## 6. 推荐 Baseline
- 贪心最近邻算法（Nearest Neighbor Baseline for TSP）；
- 经典 Dijkstra 单源最短路径；
- 独立点对直接输送基准。

## 7. 必须验证的东西
- **流量守恒定律（Flow Conservation）**：对所有非源汇节点，入流总和严格等于出流总和（误差 $\le 10^{-6}$）；
- **容量上限检验（Capacity Invariant）**：$\forall (u, v) \in E, \quad f(u, v) \le c(u, v)$；
- **连通性与子回路消除**：输出路径必须形成单一连通大回路，无孤立游离小环。

## 8. 常见数学错误
- 图为有向图但误用无向图邻接矩阵，导致逆向通行违反单行道物理事实；
- 忽略了三角不等式成立条件（$w_{ik} \le w_{ij} + w_{jk}$）。

## 9. 常见代码错误
- 节点编号从 0 或 1 开始未对齐导致数组越界；
- MTZ 约束变量 $u_i$ 上下界设置错误使得合法解被误杀。

## 10. 论文表达规范
- 绘制带有真实地理坐标或网络拓扑的可视化路线图（标记起点、途径点、终点与流量箭头）；
- 汇报关键指标：总路径长度、总成本、网络瓶颈边（Bottleneck Edges）及其对偶影子价格（Dual Values）。
## 11. 典型优秀论文机制
- 分层图/多式联运：把运输方式或时间窗扩展为分层节点，最短路一次求解替代逐层拼接；
- 用最小费用最大流的对偶价格（影子价格）定位瓶颈边并指导扩容建议。

## 12. 推荐实现入口
`networkx`（`shortest_path` / `max_flow_min_cost`，需自行安装）；带复杂侧约束时建 MILP 走 `scripts/scaffold/opt_milp.py`。
