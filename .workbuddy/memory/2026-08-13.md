# 2026-08-13

## 按私用竞赛 roadmap 完成 Phase A P0 改造

依据 `math_model_skill_private_competition_roadmap.md` 完成 Phase A P0 全部六项：

1. **Assumption Fork**：`model_contract` schema 1.3 新增 `assumption_forks`（≥2 解释 + checks + selected/selection_reason 或 unresolved_risk，未解决必须同步到 unresolved_questions/decision.unresolved_risks）。
2. **Typed provenance**：`parameter_plan` 自由文本 `source_or_estimator` 改为六类 oneOf（GIVEN/DERIVED/ESTIMATED/CALIBRATED/ASSUMED/POLICY），各带强制字段。
3. **Model identity**：model 可声明 `identity`（canonical_name/forbidden_aliases/objective_form/defining_equations），QA 扫摘要/正文禁止别名。
4. **Derived Result Engine**：新 `schemas/derived_results.schema.json` + `scripts/derive_results.py`（relative_change/ratio/pp/mean/std 等，Decimal 计算，FAIL run 拒绝派生）；接入 `compile_writer_package.py --derived-results` 与 `check_consistency.py --derived-results`（含 stale frozen 引用检测）。
5. **Canonical unit/scale**：frozen result 新增 display_scale/display_unit/display_label，freeze 时强制 display_value == round(value/scale, precision)。
6. **有限数学语义检查**：新 `scripts/qa/check_math_semantics.py`（CVaR 方向/置信度、correlated_inputs→correlation_spec、Cholesky→PD、全局最优措辞需 gap/bound 证据、probability/correlation 值域、单位量级漂移）；合同级检查挂入 `check_modeling_plan.py`，文本级挂入 `run_deterministic_qa.py`（新增 math_semantics check）。

测试：新 `tests/test_competition_upgrades.py`（19 个回归测试，覆盖 roadmap §27 的 T2/T3/T5/T6/T7/T8）；全套 89 个测试通过。

## 关键约定（复用价值）

- 仓库自研 JSON Schema 子集校验器（`scripts/qa/validate_contracts.py`）：只支持 allOf/oneOf/const/enum/pattern 等，**不支持 if/then、dependentRequired、exclusiveMinimum**；条件必填字段要用 oneOf + const 分支表达。
- 测试套件全量约 5-6 分钟，Bash 默认 2 分钟超时会被杀且看不到汇总——跑全量必须显式加长 timeout。
