# Initial Local Variants

Run `scripts/dev/build_figure_gallery.ps1` to materialize these repository-owned
Draw.io previews, vector exports, and editable sources. They deliberately reuse
only this repository's archetype specs; they do not copy the external seed XML.

| Gallery family | Variant 01 composition | Variant 02 composition |
|---|---|---|
| `research-framework` | left-to-right research framework | parallel integration with shared output |
| `model-pipeline` | staged computational pipeline | module architecture with grouped internals |
| `parallel-integration` | parallel branch convergence | central research framework with validation rail |
| `optimization-loop` | cyclic optimization | staged pipeline with an explicit validation stage |
| `method-architecture` | modular method architecture | parallel integration over a shared result |

Use `brief.md` in a real competition figure directory to record the message,
source evidence, reference choices and prohibited content. These gallery
examples establish visual alternatives, not a substitute for an evidence-bound
figure brief. `mechanism-illustration` remains an illustration-only family: it
must be created through the image-generation route and cannot be filled with a
generic Draw.io workflow merely to satisfy a gallery count.
