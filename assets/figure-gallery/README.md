# Local Figure Gallery

`_external-seeds/` is reference-only. This directory is for repository-owned
examples that demonstrate visual grammar without reusing upstream labels or
topology. The currently maintained editable archetype sources live in
[`../drawio/archetypes`](../drawio/archetypes/README.md); new curated examples
belong in the directories below.

```text
research-framework/<variant>/
model-pipeline/<variant>/
parallel-integration/<variant>/
optimization-loop/<variant>/
method-architecture/<variant>/
mechanism-illustration/<variant>/
```

Each variant contains `brief.md`, `notes.md`, `figure.drawio`, `figure.svg`,
and `preview.png`. Build at least two visually distinct variants before making
one archetype a default. A visual reference changes composition only; all
nodes, edges, labels, sources, and result claims must still originate in the
current project.
